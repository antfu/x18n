---
title: Typegen
description: Generate TypeScript types for your keys from the source locale, so that tsc rejects a key that doesn't exist.
---

`x18n typegen` writes the messages of the source locale as the types of your i18n library. `tsc` then fails on a key that doesn't exist, and your editor completes the ones that do.

It works with any format and layout x18n reads, since the types come from x18n's merged view of the messages and not from one JSON file.

## Setup

Turn it on in the config:

```yaml [x18n.config.yml]
typegen: true
```

Or choose the file:

```yaml [x18n.config.yml]
typegen:
  output: src/x18n.d.ts
```

Then write the file, and make sure your `tsconfig.json` includes it:

```sh
x18n typegen
```

Commit the file, so that `tsc` works in CI without running x18n first.

Typegen is off by default, and it does nothing in a project with neither a `tsconfig.json` nor `typescript`.

## Result

With i18next, these messages:

```json [locales/en/translation.json]
{
  "title": "Hello",
  "greet": "Hi {{name}}"
}
```

give these checks in `tsc`:

```ts
i18next.t('title')
i18next.t('greet', { name: 'Ada' })

// @ts-expect-error: not a key
i18next.t('nope')

// @ts-expect-error: not a param of this message
i18next.t('greet', { nam: 'Ada' })
```

## Keeping it current

| Where | What happens |
| --- | --- |
| `x18n typegen --watch` | Writes the file again when messages change. |
| Language server | Writes the file again shortly after a resource changes. |
| `x18n check` | The [`typegen-stale`](/checks/typegen-stale) check fails when the file is missing or out of date. |

## Libraries

`i18next` and the presets built on it, such as `react-i18next`, have a target. `x18n typegen` says so when a project has no target.

A plugin adds a target with its `typegen` hook: an `id`, the default `output` file, `render`, which turns the source messages into the file, and an optional `usable`, which says whether the project can use the file (the i18next target needs TypeScript). See [Capabilities](/plugins/capabilities).
